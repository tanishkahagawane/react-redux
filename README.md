# Redux Toolkit Full Course 2026

This repository accompanies the **Redux Toolkit Full Course 2026** . This project demonstrates how to manage state in *React* applications using modern *Redux Toolkit* (RTK) practices.

## Project Overview

This course guides you through building a production-ready **E-commerce project** from scratch . You will learn how to efficiently manage cart state, handle API calls, and persist data.

## Key Learnings

*   **Redux Architecture**: Understand the flow of *Actions*, *Reducers*, *Store*, *Dispatch*, and *Selectors*.
*   **RTK Implementation**: Master creating *Slices* to handle state logic without separate action/reducer files.
*   **Async Operations**: Utilize `createAsyncThunk` for API integrations without needing external middleware like Saga or traditional Thunk .
*   **Data Persistence**: Implement *Local Storage* to keep cart items available even after page refreshes.
*   **Routing**: Integrate *React Router DOM* to manage multiple pages within the application.

## Getting Started

1.  **Setup**: The project uses *Vite* to create the *React* environment.
2.  **Dependencies**: Ensure you have *Node.js* installed, then install the necessary packages for *Redux Toolkit* and *React Router* .
3.  **Debugging**: Learn to use *Redux DevTools* for monitoring state changes in real-time.

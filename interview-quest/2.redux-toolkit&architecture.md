### 48. How do you handle normalized state?

Instead of:

```js
posts: [
  {
    id: 1,
    author: {
      id: 10,
      name: "John",
    },
  },
];
```

you might have:

```js
users: {
  10: {
    id: 10,
    name: "John"
  }
},
posts: {
  1: {
    id: 1,
    authorId: 10
  }
}
```

**Why is normalization useful?**

# Redux Toolkit Full Course 2026

This repository contains the source code for the **Redux Toolkit** tutorial, a comprehensive course designed to help you master modern state management in _React_ applications.

## Project Overview

In this course, we build a real-world **E-commerce project** from scratch, featuring essential state management functionality including:

- **Product listing** fetched from a dummy API
- **Add to cart** functionality with persistent state
- **Remove items** and **clear cart** features
- **Quantity adjustment** and **total price calculation**

## Key Learnings

- **Redux vs. Redux Toolkit**: Understanding the shift from complex legacy Redux to the simplified RTK approach.
- **Core Concepts**: Mastering _Store_, _Slices_, _Reducers_, and _Actions_ .
- **Asynchronous Operations**: Using _createAsyncThunk_ for API calls and handling side effects .
- **Integration**: Setting up _React Router_ for navigation and _Redux DevTools_ for debugging .

## Getting Started

1.  Clone the repository to your local machine.
2.  Install dependencies using `npm install`.
3.  Run the development server with `npm run dev`.
